# Тест на дружбу — сайт с регистрацией

В проекте есть регистрация и вход, личные аккаунты, сохранение правильных ответов, ссылки на тест, результаты и email-уведомления (при настроенном SMTP).

## ВАЖНО: почему появляется `Failed to fetch`

`Failed to fetch` означает, что браузер не достучался до сервера. Одного заполнения `.env` недостаточно: сервер Node.js должен быть запущен, а PostgreSQL — доступна.

**Не открывай `public/index.html` двойным щелчком и не запускай его через VS Code Live Server.** Так страница открывается отдельно от API и регистрация не сможет отправить запрос.

## Запуск на Windows

1. Установи Node.js 20 или новее и PostgreSQL (либо создай облачную PostgreSQL-базу, например Neon/Supabase).
2. Распакуй архив.
3. Открой папку `friendship-test-project`.
4. Скопируй `.env.example` и назови копию `.env`.
5. В `.env` обязательно укажи рабочую строку базы данных:
   - `DATABASE_URL=postgresql://...` — настоящая строка подключения к PostgreSQL, не пример из файла.
   - `PGSSL=true`, если провайдер базы требует SSL (для Neon/Supabase обычно требуется SSL).
   - `SESSION_SECRET` — длинная случайная строка.
6. Открой терминал именно в папке `friendship-test-project` и выполни:

   ```bash
   npm install
   npm start
   ```

7. Не закрывай окно терминала. Открой браузер и перейди на `http://localhost:3000`.
8. Проверь адрес `http://localhost:3000/api/health`. Если всё настроено, увидишь JSON с `"ok":true` и `"database":"connected"`.
9. Только после этого регистрируй аккаунт.

## Если `Failed to fetch` не исчез

- Если `http://localhost:3000` вообще не открывается — сервер не запущен или завершился с ошибкой. Посмотри сообщение в терминале.
- Если `/api/health` показывает `database: disconnected` — неверный `DATABASE_URL`, не включён нужный SSL (`PGSSL=true`) или база недоступна.
- Если `npm start` пишет, что `DATABASE_URL` не задан — файл `.env` отсутствует, назван `.env.txt` или находится не рядом с `server.js`.
- Если сайт опубликован на хостинге — проверь, что опубликован весь проект, команда запуска `npm start`, а переменные `DATABASE_URL`, `SESSION_SECRET` заданы в настройках хостинга.

## Email-уведомления

Email не нужен для самой регистрации. Для писем отдельно настрой `OWNER_EMAIL`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS` и `SMTP_FROM`. Если SMTP не настроен, результаты всё равно будут храниться в кабинете в разделе «Ответы друзей».

## Безопасность

Не загружай `.env` в GitHub и никому не отправляй пароль базы данных, пароль приложения почты или `SESSION_SECRET`. В `.gitignore` уже добавлен `.env`.
